# Yêu cầu chức năng

## 1. Quản lý thành viên

- Xem danh sách thành viên
- Thêm thành viên mới
- Sửa thông tin thành viên
- Xoá thành viên
- Tìm kiếm theo tên hoặc mã

## 2. API

- Backend cung cấp endpoint REST
- Frontend gọi API bằng axios hoặc fetch
- Trả về dữ liệu dạng JSON

## 3. Giao diện

- Hiển thị danh sách thành viên
- Form thêm/sửa thông tin
- Nút xoá và cập nhật
- Hiển thị trạng thái loading/error

## 4. Bảo mật & chất lượng

- Không lưu secret vào mã nguồn
- Validate dữ liệu đầu vào
- Có test đơn vị cho controller/service
